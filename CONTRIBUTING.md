# Contributing

How to propose a change to agent-task.

## Setup

[Development](docs/development.md) has the setup, the checks and the scripts.

## Pull requests

Outside contributors fork the repo, work on a branch and open a pull request against `main`. Maintainers with push access land work as [`AGENTS.md`](AGENTS.md) says.

Commit messages follow the commit rule in [`AGENTS.md`](AGENTS.md): `.githooks/commit-msg` judges each one locally, and the `commits` workflow judges each commit a pull request brings.
