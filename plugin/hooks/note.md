# agent-task

Queued and running work lives in `agent-task`, not in a ledger, a notes file or a plan. Queue a task with `agent-task add`, start it with `agent-task start`, hand it back for review with `agent-task review`, and close it with `agent-task done` however its work ended. `agent-task ask` queues a question or step for the owner, which is never started and `done` closes. `agent-task list` shows what is running, in review, ready and waiting, and what waits on the owner, and `agent-task --help` gives every command and flag. `agent-task halt "<reason>"` halts all agent work on this machine: while it is raised, edits, shell commands other than `agent-task` and new agents are refused, and only the owner lifts it with `agent-task resume`. A refusal names the act that resolves it; do it rather than working around the tool.
