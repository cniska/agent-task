# agent-task

Queued and running work lives in `agent-task`, not in a ledger, a notes file or a plan. Queue a task with `agent-task add`, start it with `agent-task start`, hand it back for review with `agent-task review`, and close it with `agent-task done` however its work ended. `agent-task list` shows what is running, in review, ready and waiting, and `agent-task --help` gives every command and flag. A refusal names the act that resolves it; do it rather than working around the tool.
